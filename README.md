# Customer Behavior Data Analytics Project

## Overview

This project focuses on analyzing customer shopping behavior using a structured data analytics workflow. The goal is to extract meaningful insights from raw data and present them through interactive dashboards and reports for better decision-making.

The project includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based querying, and visualization using Power BI.

## Dataset

* The dataset contains customer shopping behavior information such as demographics, purchase patterns, and transaction details.
* Data is loaded and processed using Python.

## Tools & Technologies

* **Python** (Pandas, NumPy)
* **MySQL** (for querying and data analysis)
* **Power BI** (for dashboard creation)
* **Gamma** (for presentation/PPT creation)

## Project Steps

1. **Data Loading**

   * Imported dataset into Python using Pandas.

2. **Exploratory Data Analysis (EDA)**

   * Analyzed distributions, trends, and relationships.
   * Identified patterns in customer behavior.

3. **Data Cleaning**

   * Handled missing values and duplicates.
   * Standardized and formatted data for consistency.

4. **SQL Analysis (MySQL)**

   * Exported cleaned data to MySQL.
   * Performed queries to extract insights such as:

     * Customer segmentation
     * Purchase trends
     * Revenue analysis

5. **Dashboard Creation (Power BI)**

   * Built interactive dashboards to visualize key metrics.

6. **Reporting & Presentation**

   * Created a structured report summarizing findings.
   * Developed a presentation using Gamma for stakeholder communication.

## Dashboard

The Power BI dashboard includes:

* Customer segmentation overview
* Sales and revenue trends
* Product/category performance
* Key performance indicators (KPIs)

## Results & Insights

* Identified high-value customer segments.
* Discovered purchasing trends across categories.
* Highlighted factors influencing customer behavior.
* Provided actionable insights for improving sales and marketing strategies.

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-link>
   ```

2. Install required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

3. Run the Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Import cleaned dataset into MySQL and run SQL queries.

5. Open the Power BI file (.pbix) to view the dashboard.

6. Review the report and presentation for final insights.
